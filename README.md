# Artefatos do Projeto
Este repositório centraliza toda a documentação técnica, diagramas de modelagem e artefatos de engenharia desenvolvidos ao longo do ciclo de vida do projeto.

## Sumário de Artefatos

- **Artigo Científico** — Documentação acadêmica e fundamentação teórica do projeto.
- **Diagrama de Caso de Uso** — Mapeamento das interações entre os atores e as funcionalidades do sistema.
- **Diagrama de Redes** — Topologia e infraestrutura de rede/comunicação da aplicação.
- **Canvas** — Modelo visual do negócio (Business Model Canvas / Lean Canvas).
- **Diagrama de Classe** — Estrutura estática, classes, atributos, métodos e relacionamentos.
- **Diagrama de Objeto** — Instâncias de objetos e seus estados em um determinado momento de execução.
- **Scrum** — Planejamento ágil, papéis, sprints, backlog e fluxo de trabalho.
- **SWOT** — Análise das Forças, Oportunidades, Fraquezas e Ameaças da solução.
- **Modelagem de Banco de Dados** — Modelo Entidade-Relacionamento (DER/MER) e esquemas do banco.
